# Media

Screenshots and the walkthrough recording for the README's
"Video and screenshots" section. Kept out of the source tree so that renaming a
page does not silently break a picture of it.

Expected files, named exactly:

| File | What it shows |
|---|---|
| `walkthrough.md` | a link to the recorded walkthrough, once it is made |
| `console-overview.png` | the console's overview page: spend, latency, errors |
| `console-reliability.png` | the Reliability page with remaining error budgets |
| `console-evals.png` | the Evaluations page: the conversation cases against the baseline |
| `grafana-gateway.png` | the gateway overview dashboard in Grafana |

Screenshots are taken at 1440 pixels wide against the local stack with seeded
traffic, so no real tenant, key or personal value appears in one. The recording
is a link rather than a committed file: this repository does not carry video.

Until a file lands here the README names the section and says the media is
pending; it does not link a path that does not exist.
